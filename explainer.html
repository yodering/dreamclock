Your if-statement is a neural network.

handwired rewrites ordinary code as a neural network. Nothing is trained. The weights are worked out from the code, so the network gives exactly the same answers.

A neural network only knows three moves: multiply, add, and ReLU, which is max(0, x). Drag the sliders and watch the code and the network agree.

Now do every line
handwired does this for whole programs: every comparison, branch, min and max. A toggle switch, a window manager and a search over 100k JSON docs all become one network.

    
It runs on a GPU
A network is mostly one big matrix multiply. GPUs are built for that, so code written one step at a time can run massively in parallel.

    
It can learn
The code jumps, but the network slides smoothly between whole numbers (see the plot). Smooth means you can take gradients, so you can train a hand-written program, or bolt it onto a trained model.
